# Rogue Terminal

**A modern, powerful hybrid terminal + editor with built-in AI assistance.**

Rogue Terminal combines a real PTY terminal, a full-featured code editor, organized cheat sheets, and a smart AI assistant — all in one clean interface.

![Screenshot](https://github.com/CraigNSt/Rogue-Terminal/raw/main/screenshots/main.png)

## Features

- **Tabbed Real PTY Terminal**
  - Add and delete tabs freely
  - Choose your shell: **Bash, Zsh, PowerShell, Cmd**
  - Full SSH support (with password authentication)

- **Monaco Editor** (same editor used in VS Code)
  - Edit scripts, JSON configs, and files directly
  - Smart save with optional elevated privileges (`sudo rogue-edit`)

- **Organized Cheat Sheets**
  - Hierarchical command library
  - Easily searchable and expandable

- **Built-in AI Assistant**
  - Supports OpenAI, Anthropic (Claude), Grok, Ollama, and more
  - Context-aware help directly in the app

- **Cross-Platform**
  - Windows, Linux (DEB & RPM), macOS

## Quick Start

1. Download and install the latest version
2. Open the app and accept the disclaimer
3. Start a new terminal tab and choose your preferred shell
4. Explore the cheat sheets on the left sidebar
